# Asawir — 3D Portfolio

Personal immersive portfolio built with React, Three.js / React Three Fiber, Drei, Framer Motion, and Vite.

## Features

- Scroll-driven portfolio sections
- Interactive 3D WebGL visuals
- Responsive mobile layout
- AI Engineer Intern experience at OctaSynx
- Skills and technology toolkit
- Interactive Draw → Constellation art section
- Selected projects and contact section
- Custom cursor and motion interactions

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
